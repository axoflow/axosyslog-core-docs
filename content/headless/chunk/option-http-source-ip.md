## ip() or localip() {#ip}

|          |         |
| -------- | ------- |
| Type:    | string  |
| Default: | `0.0.0.0` |

*Description:* The IP address to bind to. By default, {{% param "product.abbrev" %}} listens on every available interface. Note that this is not the address where messages are accepted from.
